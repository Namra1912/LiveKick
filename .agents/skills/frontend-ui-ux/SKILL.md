# Frontend UI/UX & Design Craftsmanship

## Core Principles
1. **Anti-Slop Aesthetics**: Avoid generic browser defaults, plain blue/red colors, unstyled form controls, or boxy layouts. Interfaces must look sleek, deliberate, and modern.
2. **Typography & Hierarchy**:
   - Use clean modern font stacks (e.g., Inter, Outfit, system-ui).
   - Maintain clear scale hierarchy (`h1` > `h2` > `h3` > `p`) with proportional font sizes and line heights (1.4–1.6).
3. **Color System & Contrast**:
   - Use curated color palettes (sleek dark modes, warm neutrals, soft accent colors).
   - Use subtle borders (`1px solid rgba(0, 0, 0, 0.08)`) and soft box-shadows instead of thick harsh outlines.
4. **Spacing & Alignment**:
   - Use an 8px grid system (8px, 16px, 24px, 32px, 48px).
   - Use Flexbox & CSS Grid for responsive alignment across mobile and desktop screens.
5. **Micro-Interactions & Feedback**:
   - Add active, hover, and focus states for all interactive elements (buttons, inputs, cards).
   - Use smooth transitions (`transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`).
6. **Clean React Code**:
   - Keep components modular, focused, and readable.
   - Respect the user's current learning progress—avoid over-complicating code with unlearned advanced concepts unless requested.
